# План реализации

Пошаговый чеклист для автономной сессии. Каждый шаг заканчивается зелёными проверками.
Не переходить к следующему шагу, пока текущий не закрыт.

Источник требований — `docs/SPEC.md`. При расхождении плана и спеки правда в спеке.

**Статус:** шаги 0–16 закрыты. Отметка `[x]` — код, тесты и браузерная проверка на месте.
Ниже под каждым шагом — что именно сделано и чем проверено.

## Шаг 0. Инициализация проекта — [x]

**Сделать:**

1. `pnpm init`, `package.json`:
   - `"name": "poker-night"`, `"private": true`, `"version": "0.1.0"`, `"license": "MIT"`,
     `"type": "module"`, `"packageManager": "pnpm@10.7.0"`.
2. Установить:
   ```bash
   pnpm add preact @preact/signals kinu idb lucide-preact
   pnpm add -D vite @preact/preset-vite typescript vitest @biomejs/biome
   ```
3. `tsconfig.json`: `strict`, `jsxImportSource: "preact"`, `target: "ES2022"`,
   `moduleResolution: "bundler"`, `noUncheckedIndexedAccess: true`.
4. `vite.config.ts`: плагин preact, `base: '/poker-night/'`, `build.target: 'es2022'`.
5. `biome.json`: формат 2 пробела, одинарные кавычки, `noUnusedVariables: error`.
6. Скрипты:
   ```json
   {
     "dev": "vite",
     "build": "vite build",
     "preview": "vite preview",
     "typecheck": "tsc --noEmit",
     "test": "vitest run",
     "lint": "biome check src"
   }
   ```
7. `index.html` с `<div id="app">`, `<meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover">`,
   `<meta name="theme-color" content="#0d1512">`.
8. `.gitignore`: `node_modules`, `dist`, `.DS_Store`.

**Готово, когда:** `pnpm dev` поднимает пустую страницу, `pnpm typecheck` зелёный.

## Шаг 3. Сводка игры — [x]

**Файл:** `src/core/totals.ts`.

1. `derivePlayers(game): PlayerState[]` — чистый пересчёт из журнала (§3.4).
2. `chipsOnHand`, `finalChips`, `boughtChips`, `netChips`, `netCoins`,
   `externalOutChips` — по формулам §3.4.
3. `gameTotals(game): GameTotals` — `{ players, sumNetChips, reconciled,
   bankRemainingChips, bankRemainingCoins, uncoveredCount }` (§3.4.2).
4. `bankState(game)` — `{ total, dealt, returned, remaining, coveredStacks }`.

**Важно:** производные величины **не сохраняются** в игру. `<Player>` в базе —
только `id`, `name`, `seat`. Все числа считаются на лету.

**Тесты** (`src/core/totals.test.ts`) — три golden-примера из спеки §3.5 (A, B, C)
обязательны. Дополнительно: сценарий с незафиксированным остатком (`finalChips === null`),
двойной `finalStack` (применяется последний), `cashout` + `finalStack` вместе.

**Готово, когда:** `pnpm test` зелёный.

## Шаг 4. Валидация — [x]

**Файл:** `src/core/validate.ts`.

Функции возвращают `{ ok: boolean; errors: string[]; warnings: string[] }`:

- `validateKit(kit)` — 2..8 номиналов, возрастающие, уникальные цвета, count ≥ 0.
- `validatePlayers(players)` — 2..12, непустые, уникальные, ≤ 24 символов.
- `validateGameSettings(s)` — стек > 0, курс ≥ 1, SB ≥ мин. номинал, K ∈ {4,5,10}, резерв ≥ 0.
- `validateDealFits(deal, n, kit)` — `a[i]*n ≤ counts[i]`.

**Готово, когда:** тесты на каждый кейс.

## Шаг 5. Сериализация ссылки — [x]

**Файл:** `src/core/payload.ts`.

1. `encodePayload(data): Promise<string>` — JSON → `deflate-raw` → байт `0x01` → Base64URL.
2. `decodePayload(s): Promise<Payload>` — обратный путь, поддержка `0x01`/`0x02`.
3. `payloadFromGame(game): Payload` и `resultsFromPayload(p): Results`.

**Тесты:** roundtrip для 2/4/6/12 игроков; длина Base64URL < 800 для 12 игроков
с именами по 24 символа; декодирование мусора не падает, а возвращает `null`;
декодирование payload с лишними полями не падает.

**Сделано дополнительно:** `payloadFromGame` берёт счётчики из журнала (докупки и внешние
покупки раздельно) и кладёт `h` — фишки на руках — при незафиксированном остатке, иначе
публичная страница считала бы `net` иначе, чем экран итогов. Спека §9.2 обновлена.

## Что нельзя делать

- Добавлять зависимости вне списка из спеки §2.1.
- Делать сетевые запросы в рантайме (кроме загрузки самого приложения).
- Хранить производные величины в базе (только журнал + настройки).
- Использовать `any` в публичных сигнатурах.
- Писать UI-тесты вместо тестов ядра: приоритет — покрытие `src/core/**`.

## Definition of Done для любого шага

1. Код написан и типизирован без `any`.
2. Тесты на новую логику ядра добавлены и зелёные.
3. `pnpm typecheck && pnpm test && pnpm lint && pnpm build` — зелёные.
4. Ручная проверка сценария в браузере (для UI-шагов) на ширине 375 px.
5. Если поведение отличается от спеки — спека обновлена **до** кода, а не после.
